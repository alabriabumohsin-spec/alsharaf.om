# شاليهات الشرف · alsharaf.om

موقع الحجز. يُستضاف على GitHub Pages، ويقرأ الأيام المحجوزة من جدول Google Sheets "حجوزات شاليهات الشرف".

## الملفات

| الملف | ما هو |
|---|---|
| `index.html` | الموقع كاملاً |
| `images/` | صورة الواجهة وصور شاليه القمر |
| `CNAME` | يربط الموقع بالنطاق alsharaf.om |
| `_claude-pages/` | ملفات صفحات claude.ai (الموقع القديم وصفحة الفواتير). لا تُرفع إلى GitHub |

## كيف يعرف الموقع الأيام المحجوزة

في جدول الحجوزات تبويب اسمه **"الموقع"**، يحسب تلقائياً من صفحات الأشهر: لكل تاريخ، هل الشاليه محجوز أو لا. هذا التبويب وحده منشور على الويب بصيغة CSV، وفيه تواريخ وأرقام شاليهات فقط، بدون أسماء أو أرقام هواتف أو مبالغ.

- **حجز جديد:** اكتب اسم الضيف تحت اليوم في صفحة الشهر، ويظهر في الموقع محجوزاً خلال 5 دقائق تقريباً. ما تحتاج تضغط أي زر.
- **لا تحذف تبويب "الموقع" ولا تغيّر ترتيب صفوف الشاليهات** في صفحات الأشهر (القمر صف 6، الزيتون صف 10، الرمان صف 14).
- **شهر جديد بعد أكتوبر 2027:** انسخ صفحة شهر بنفس التصميم وسمّها مثل "نوفمبر 2027"، ومدّ معادلة التاريخ في تبويب "الموقع".

## رفع الموقع على GitHub

1. في github.com اضغط **New repository**. سمّه `alsharaf.om`، واختر **Public**، ثم **Create repository**.
2. اضغط **uploading an existing file**، وارفع: `index.html` و`CNAME` و`README.md` ومجلد `images`. ثم **Commit changes**.
3. من **Settings ← Pages**:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `(root)` ثم **Save**
   - تحت **Custom domain** اكتب `alsharaf.om` واحفظ.
